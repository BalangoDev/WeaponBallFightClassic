# Weapon Ball Fight Classic
GDevelop JSON &amp; Assets for Weapon Ball Fight

# How to use
1. Install [GDevelop 5](https://github.com/4ian/GDevelop/releases)
2. Click the "Open a Project" button
3. Open the Weapon Ball Fight.json file

# Notes
1. The codebase is horrific spaghetti code
2. GDevelop will lag half to death if you don't have a high powered pc
3. You can do literally whatever you want with this, I don't care if you remove ads or anything. Just follow the license :)

# Firebase
* All functions that use firebase (Workshop, Missions, etc) are disabled in this version due to the api key being removed to avoid abuse. You can add an API key in the properties panel inside of GDevelop.
